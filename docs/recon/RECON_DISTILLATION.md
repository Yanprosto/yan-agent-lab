# Recon distillation

Raw D:\YAN_RECON runs are evidence, not repository memory.
Run tools\publish_minecraft_lab_oracle.ps1.

- docs/recon/generated/minecraft_lab_oracle.json
- docs/recon/generated/minecraft_lab_oracle.md

capability retrieval indexes, Universal Modder context, and the previous verified Mekanism defaults.
